## Contrat CSP

- **CSP servie** : `default-src 'self' 'unsafe-inline' 'unsafe-eval' data: blob:; connect-src 'none'; worker-src 'none'; frame-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors *; sandbox allow-scripts (BLOB_SERVE_CSP, blob_serve.rs:286, verifie de visu). + COOP same-origin (:288), COEP require-corp (:290), CORP cross-origin, X-Content-Type-Options nosniff. Pose par blob_serve_csp_middleware sur CHAQUE reponse y compris 404. iframe shell : sandbox="allow-scripts" sans allow-same-origin => origine opaque/null.`
- **check-csp fidèle ?** : FIDELITE PARTIELLE, confirme de visu. Fidele sur le COEUR : les 13 regex NETWORK (check-csp.mjs:23-37) couvrent connect-src'none' (fetch/XHR/WebSocket/EventSource/sendBeacon), worker-src'none' (Worker/SharedWorker/importScripts/serviceWorker), default-src (@import url()/remote url()/remote link/script). ECARTS : (1) le commentaire CSP l.3-4 est un SOUS-ENSEMBLE — il omet base-uri 'none', form-action 'none', frame-ancestors *, sandbox allow-scripts ; (2) NETWORK ne contient AUCUNE regle form-action ni base-uri (les deux sont dans la CSP reelle, form-action explicitement justifiee anti-exfiltration blob_serve.rs:283-285) ; (3) DRIFT doc : commentaire l.12 dit 'anime.esm.js' alors que le code l.75 lit bien 'vendor/anime.umd.js' (seul fichier present) — le code est correct, le commentaire perime ; (4) check-csp ne verifie pas COOP/COEP/CORP/nosniff (hors-scope : runtime daemon, pas asset statique).
- **Règles du gate** :
- Importer la constante BLOB_SERVE_CSP de nexus-shell-daemon-core comme source de verite (PAS re-hardcoder, PAS lire le commentaire check-csp.mjs:3-4)
- Reprendre les 13 regex NETWORK du CODE check-csp.mjs:23-37 (PAS du commentaire) : interdire partout fetch/XMLHttpRequest/WebSocket/EventSource/navigator.sendBeacon (=connect-src'none'), new Worker/new SharedWorker/importScripts/navigator.serviceWorker (=worker-src'none'), remote <link href https:>/<script src https:>/@import url()/remote url() asset (=default-src)
- 3 tiers : authored {index.html,app.js} = zero http(s) absolu + zero NETWORK ; compiled {app.css} = zero NETWORK + chaque URL absolue dans CSS_URL_ALLOW {http://www.w3.org/2000/svg, http://www.w3.org/1999/xlink, https://tailwindcss.com} ; vendored {vendor/anime.umd.js} = zero NETWORK live
- AJOUTER les 2 regles manquantes au gate (GAP confirme) : form-action 'none' => interdire <form action=> et action= dynamiques ; base-uri 'none' => interdire <base href>
- AJOUTER object-src'none' => interdire <object>/<embed> ; frame-src'none' => interdire iframes imbriquees
- Valider que app.css est charge en <link rel=stylesheet href=relatif> et vendor/*.js en classic <script src> same-origin, JAMAIS type=module (CORS impossible en origine opaque sous COEP require-corp), jamais CDN/fetch
- Test cross-crate : asserter que la liste NETWORK couvre toutes les directives 'none' de BLOB_SERVE_CSP, pour empecher tout futur drift
- **Action** : Factoriser la verite CSP en source unique (verite aujourd'hui dupliquee/desync a 3 endroits : blob_serve.rs:286 canonique, check-csp.mjs:3-12 commentaire perime+incomplet, docstring http.rs:234) : (i) export Rust BLOB_SERVE_CSP + un manifeste de regles machine-lisible derive d'elle ; (ii) check-csp.mjs ET le gate Rust de la capacite Factory consomment ce manifeste plutot que de re-derive les regex ; (iii) test cross-crate de couverture des directives 'none'. Corrections immediates a faire : commentaire check-csp.mjs:12 esm->umd, completer NETWORK avec form-action + base-uri.
