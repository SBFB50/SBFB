      Sismographe temporel

      Le temps se fige sur les à-coups, jamais sur les beats

      Un stylet trace une oscillation auto-pilotée. Tant que le tracé est lisse, tout coule. Mais dès qu'une secousse survient — le jerk (3ᵉ dérivée de la position) dépasse un seuil — toute la scène plonge au ralenti, puis repart. Aucun beat n'est scripté : c'est la physique du tracé qui déclenche le gel, via engine.speed animé. L'horloge de détection est découplée (rAF natif, jamais ralenti). Données simulées, 0 réseau.

      Pipeline de shards · propagation de couple

      L'activation traverse les couches comme une onde

      Chaque engrenage est un shard du pipeline. Quand une requête arrive, la roue motrice force : une onde de vitesse voyage de roue en roue avec retard et amortissement (couplage amont→aval = RTT relais + buffering KV) — on voit l'activation se propager. La tension entre deux roues révèle le goulot : le shard le plus lent borne le débit. Le jeu mécanique (backlash) tremble dans les à-coups. Modèle de shard_plan.rs · routing.rs. Données simulées, 0 réseau.
