## INSTRUCTIONS

1. **INGESTION** — Absorbe toutes les données ci-dessus. Identifie les lacunes critiques.
2. **CHRONOLOGIE** — Reconstuis la timeline minute par minute si possible. Signale les trous.
3. **GRAPHE RELATIONNEL** — Cartographie TOUTES les connexions entre les entités (personnes, lieux, objets, comptes).
4. **RECHERCHE WEB** — Utilise la recherche web pour :
   - Vérifier les faits publiquement disponibles
   - Chercher des articles de presse sur l'affaire
   - Cross-référencer les noms, lieux, et événements
   - Trouver des affaires similaires (modus operandi)
5. **ANOMALIES** — Identifie chaque incohérence, contradiction, coïncidence suspecte.
6. **HYPOTHÈSES** — Génère minimum 3 hypothèses scorées (plausibilité 0-100%).
7. **PISTES** — Propose les actions d'investigation prioritaires par impact.
8. **ANGLES MORTS** — Dis-moi ce qui manque et pourrait tout changer.

Sois exhaustif. Sois impartial. Montre ton raisonnement étape par étape.
