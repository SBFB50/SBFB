## INSTRUCTIONS

1. **PROFIL CRIMINEL** — Déduis un profil probable de l'auteur basé sur le MO
   - Âge estimé, sexe, niveau d'organisation, possible profession
   - Relation probable avec la victime (inconnu, connaissance, intime)
   - Motivation probable (financière, passionnelle, sexuelle, pouvoir, idéologique)

2. **RECHERCHE D'AFFAIRES SIMILAIRES** — Utilise la recherche web pour trouver :
   - Des affaires avec un MO identique ou très proche
   - Dans la même zone géographique
   - Dans la même période temporelle
   - Avec le même profil de victime
   - Même si dans d'autres pays

3. **ANALYSE CROISÉE** — Pour chaque affaire similaire trouvée :
   - Points communs avec notre cold case
   - Différences significatives
   - Même auteur possible ? Score de probabilité (0-100)
   - L'affaire a-t-elle été résolue ? Si oui, le coupable pourrait-il être lié ?

4. **PATTERN SÉRIEL** — Existe-t-il un pattern qui suggère un auteur en série ?
   - Escalade ou dé-escalade dans la violence
   - Évolution du MO
   - Intervalles temporels
   - Migration géographique
