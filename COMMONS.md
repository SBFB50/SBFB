# SBFB Commons

Convention anti-capture du projet SBFB.

## Licence

Le code du protocole SBFB est sous **AGPL-3.0-or-later** (licence
OSI-approved, copyleft reseau). Quiconque modifie et deploie le
protocole doit rendre les modifications disponibles sous la meme
licence.

## Gouvernance

- **Pas de CLA** (Contributor License Agreement). Les contributions
  restent sous AGPL-3.0. Personne ne peut re-licencier le code.
- **Pas de fondation**. Le projet est maintenu par un mainteneur
  solo, pattern OpenBSD.
- **Pas de governance token**. Pas de vote token-weighted, pas de
  DAO, pas de tokenomics.

## Apps du reseau

Les apps deployees sur le reseau SBFB sont a **source verifiable**
(le code source est accessible et la provenance est attestee par
le noeud qui a deploye). Le terme "open source" est reserve au
code SBFB lui-meme (AGPL-3.0 OSI). Les apps ne sont pas
automatiquement open source — chaque app a sa propre licence.

## Contributions

- Fork encouraged. Le protocole P2P est concu pour que n'importe
  qui puisse forker une app et deployer sa propre version.
- Contributions bienvenues via pull request. Revue par le
  mainteneur.
- Signalement de bugs et suggestions via issues.

## Ce que ce document n'est PAS

- Pas un whitepaper.
- Pas un pitch investisseur.
- Pas une roadmap produit (voir `.planning/` pour le planning).
